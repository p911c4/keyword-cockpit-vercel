Keyword Cockpit 소개

안녕하세요, Keyword Cockpit(키워드 콕핏)을 만들고 운영하는 뉴카입니다.

IT 엔지니어로 일하며 데이터를 다뤄왔고, 여행 블로그를 직접 운영하면서 키워드 분석이 콘텐츠 성과를 좌우한다는 것을 경험으로 배웠습니다. 기존 키워드 도구들을 쓰면서 느꼈던 불편함 — 여러 사이트를 오가며 검색량과 노출 순위를 따로 확인해야 하는 번거로움 — 을 직접 해결하고자 이 도구를 설계하고 개발했습니다.

기획부터 설계, 개발, 배포, 운영까지 전 과정을 운영자가 직접 수행하고 있으며, 도구를 만들며 얻은 인사이트와 키워드 분석 노하우는 공식 블로그(keywordcockpit.com)의 제작 노트에 기록하고 있습니다.

무엇을 할 수 있나요?

  • 키워드 분석: 네이버 검색광고 데이터 기반 월간 검색량(PC/모바일), 경쟁도, 연관 키워드, 12개월 검색 트렌드를 확인합니다. 상단에서 소스를 전환하면 구글 광고 키워드 플래너의 검색량 구간, 경쟁도, 페이지 상단 입찰가가 더해집니다. 통합 보기에서는 두 엔진의 같은 항목이 좌우로 나란히 놓여 항목별로 바로 비교됩니다.
  • 블로그 지수: 블로그 ID만 입력하면 활동 지표(LV.1~9)를 조회합니다. 키워드별 노출 순위는 네이버 블로그 검색 API의 정확도순 결과가 실제 노출 순서와 어긋나는 현상이 확인되어 현재 표시를 중단했습니다.
  • 노출 레이더: 최근 포스팅 15개의 해시태그에서 의도 키워드를 자동 추출합니다. 포스팅 지수는 배점의 절반 가까이가 노출 순위에 의존하는 구조라, 순위 조회와 함께 산출을 중단한 상태입니다.

모든 기능은 무료이며 회원가입 없이 사용할 수 있습니다. 데이터는 네이버 검색광고 API, 네이버 데이터랩, 네이버 검색 API, 그리고 Google Ads API(키워드 플래너)에서 가져옵니다. 구글 지표는 제공처의 호출 부담을 줄이기 위해 7일간 캐시하며, 나머지는 실시간 조회입니다.

운영 원칙

  • 네이버와 구글의 공식 API 데이터만 사용하며, 자체 추정 지표(활동 지수·기회 지수)는 산정 원리를 각 페이지에 공개합니다.
  • 구글 지표는 키워드 아이디어 조회 한 가지 기능만 읽기 전용으로 사용합니다. 검색량은 제공처의 표기 방식대로 구간으로만 표시하며, 가져온 데이터를 재배포하거나 파일로 내보내지 않습니다.
  • IP 주소 등 개인 식별 정보는 저장하지 않습니다. 서비스 개선을 위한 익명 통계(검색 키워드·방문 수)만 30일간 보관 후 자동 삭제합니다.
  • API 제공처의 호출 제한을 준수하며, 과도한 자동화 요청을 지원하지 않습니다.
